Task 2 - Tic-Tac-Toe AI

This project is part of my CodeSoft Artificial Intelligence Internship.

 Project Description

This project is a Tic-Tac-Toe game where a human player plays against an AI.

The AI uses the Minimax algorithm to evaluate possible moves and choose the best move during the game.

 Features

- Human vs AI gameplay
- 3x3 Tic-Tac-Toe board
- AI decision-making using Minimax
- Win detection
- Draw detection
- Input validation

 Technologies Used

- Python
- Minimax Algorithm

 How to Run

Run the following command in the terminal:

```bash
python tic_tac_toe.py
