StudentBuddy - Rule-Based Chatbot

 About the Project

StudentBuddy is a simple text-based rule-based chatbot developed using Python as part of my CodSoft Artificial Intelligence Internship

The chatbot interacts with users through the terminal and responds to different inputs using predefined rules and keyword matching.

Features

-  Responds to greetings
-  Introduces itself
-  Provides basic information about Python
-  Explains Artificial Intelligence
-  Gives simple study suggestions
-  Explains basic programming concepts
-  esponds to college-related questions
-  Tells a programming joke
-  Provides help about available topics
-  Handles goodbye messages
-  Uses keyword and pattern matching

 Technologies Used

- Python
- VS Code
- GitHub

 How It Works

The chatbot takes text input from the user and checks it against predefined rules.

Based on the matched keyword or pattern, it provides an appropriate response.

If no rule matches the user's input, the chatbot gives a default response.

 How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run

bash
python chatbot.py
